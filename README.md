# Task-03: Text Generation with Markov Chains

## Overview

This project is part of my Generative AI Internship at Prodigy InfoTech.

The objective of this task is to generate text using a Markov Chain model based on a custom text dataset.

## About the Project

A Markov Chain learns relationships between consecutive words in the training text. Based on these learned word relationships, it generates new text by selecting possible next words.

## Implementation

For this task:

- A custom text dataset was created.
- The text was split into individual words.
- Word-to-next-word relationships were stored in a Markov Chain.
- Random word selection was used to generate new text.
- The generated text was saved as `generated_text.txt`.
